# YG NIGHT STADIUM

`/pachi` の無料バーチャルパチンコ。YGチームメニューの既存入口から利用できます。既存の9人の図柄を使い、赤とクロームの筐体、金の役物、48個の外周LED、データカウンター、上皿・下皿、ハンドル、液晶を一体化しています。

## 遊び方

1. 「打ち始める」で連続発射。発射強度55前後の左打ちでSTART入賞を狙います。1球だけの発射も可能です。
2. 保留は最大4個。左→右→中央の順で図柄が止まり、リーチでは野球勝負に発展することがあります。PUSHを押さなくても結果は決着します。
3. 大当り中とRUSH中は強度80〜90前後の右打ち。大当りはアタッカー入賞でラウンドが進みます。止め打ち・弱打ちのままなら入賞を待ちます。
4. 持ち玉が0になったら無料で2,500玉を補給できます。休憩ボタン・タブ非表示で進行を停止します。
5. 「演出体験」は発射停止・飛行中の玉なし・保留なし・変動待ちで利用できます。777とラウンドを自動体験でき、持ち玉・回数・RUSH・連チャン記録を変えません。

Spaceは発射／停止（PUSH中はPUSH）、左右キーは発射強度、Pは休憩／再開。入力欄・ボタン等の操作中にはショートカットを割り込ませません。スマートフォンでは下部のクイック操作も利用できます。

## オリジナル遊技仕様

| 項目 | 設定 |
| --- | --- |
| 通常時大当り | 1/99.9 |
| RUSH中大当り | 1/39.9 |
| 初当りからのRUSH突入 | 50%（777は突入確定の見せ方） |
| ST | 50回。RUSH当り後は50回に再設定 |
| 初当り | 5R、払い出し合計750玉 |
| RUSH中当り | 10R、払い出し合計1,500玉 |
| ラウンド条件 | アタッカー10入賞、1入賞15玉 |
| 始動口／小賞球 | 3玉／5玉 |
| 発射間隔 | 600ms（100球／分） |
| 初期持ち玉／無料補給 | 2,500玉 |
| 待機保留／飛行中の玉 | 最大4個／12個 |

出玉表記は払い出し総数で、打ち出した分の差し引き前です。保留が満杯でも始動口への入賞分は払い出します。ST回数は消化した外れ変動で減り、保留への入賞だけでは減りません。

保留ticketは始動入賞で1回だけ取得します。同じticketを消化時のモードで評価するため、通常→RUSHやST終了時にも再抽選しません。進行中の当落は固定。保留色・PUSH・音・動きを減らす設定は当落を変えません。白／赤／金は結果と相関する予告で、金でも外れる場合があります。

## 描画・音と負荷

- 玉の発射時に600×620座標の軌道と到着先を確定。共有の釘・液晶との衝突を計算し、同じ軌道を描画と入賞判定で使います。ゲーム向けの誘導と障害物回避を含む近似モデルです。
- 1枚のCanvasで全玉の金属反射・回転・残像・釘接触光を描画します。Reactを毎フレーム更新しません。DPRは2まで、描画玉数は16まで、衝突音は75ms以上間隔を空けます。
- 図柄は安定した縦スクロールのリール。停止時のブレーキ、中央の低速リーチ、野球勝負、復活、777、ラウンド入賞ランプを表示します。
- 音は初期OFF。音ONの直接操作で初めてAudioContextを開始します。発射・釘・停止の機械音、予告と大当りのオリジナル音、モード別の静かな背景音をローカル合成します。音源上限48、音量調整・圧縮あり。777は対応環境で「カイリキー！！」を読み上げます。
- 休憩・非表示でタイマーと描画時間を保存し、音を止めます。離脱でタイマー・RAF・イベント購読・ResizeObserver・音声を破棄します。OSの動きを減らす設定に対応します。
- ゲームはブラウザーのメモリー内のみ。DB・API呼び出し、定期ポーリング、localStorage/sessionStorage保存を追加しません。ページ移動・再読み込みで記録がリセットされます。

## 実装と確認

確率・型は `pachinko-game.ts`、進行は `pachinko-controller.ts`、軌道は `pachinko-physics.ts`、Canvasは `PachinkoBallField.tsx`。筐体は `PachinkoPage` と `PachinkoBoard`、液晶は `SymbolDisplay` と `BaseballShow`、音は `usePachinkoAudio.ts` です。

```powershell
node scripts/verify-pachinko.cjs
node scripts/verify-pachinko-physics.cjs
node scripts/verify-pachinko-canvas.cjs
node scripts/verify-pachinko-audio.cjs
node scripts/verify-pachinko-ui.cjs
node node_modules/typescript/bin/tsc --noEmit --incremental false
node scripts/run-framework.mjs build
```

回帰スクリプトはDB・ネットワーク・音声デバイスを使いません。抽選標本、FIFO保留、払い出し、実入賞ラウンド、ST、固定した当落、長時間の実軌道連続遊技、停止・破棄を検証します。Canvas・音・操作の模擬APIテストは実ブラウザーの見た目・実際の音質の確認を代替しません。実機確認では小画面の筐体と操作、右打ちの入賞、停止中のボーナス、PUSH、音量、復帰、iOSの音ONを確認してください。
