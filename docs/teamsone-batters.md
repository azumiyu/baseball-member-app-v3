# Teams.oneの成績一覧

成績画面の「成績登録確認」の隣に「成績一覧」、その隣に「個人成績」タブを追加しています。

取得元は [YGファイヤーズの成績一覧](https://teams.one/teams/ygfires/stats/batters_table) です。選択した年・試合属性・対戦チーム・大会名の条件で表示された選手・野手26項目または投手20項目の数値を取得し、打率などの先頭の小数点や桁数もそのまま表示します。その他の絞り込み条件は元ページの既定値を使います。

「対戦チーム」「大会名」の選択肢は元ページから取得し、初期値は「指定なし」です。チームIDを含む値や、大会名の空白・記号は元の値を保持してURLエンコードします。通算でも選択条件を維持し、ブラウザ・サーバーとも全条件の組み合わせごとに15分キャッシュします。条件変更時に選択欄を保持し、Teamsへのリンクにも条件を反映します。

該当選手がいない場合は、Teams.oneの明示的な該当なし表示を空の一覧として扱い、選択欄は残します。取得元が選択条件を無視した場合は、異なる条件の成績を返さず取得失敗として扱います。Worker内の条件別ローダーは直近128条件まで保持してメモリーの増加を抑えます。

年は2022年から日本時間の現在年まで選択でき、2027年以降も年が変わると自動的に追加されます（画面の再表示・再読み込み時に反映）。初期値は現在年です。「通算」を選ぶとTeams.oneの年度指定なしの通算成績を表示します。通算でも試合属性と「規定未到達者も含む」の条件を引き継ぎ、条件ごとにキャッシュします。試合属性は「試合属性」（指定なし）・「公式戦」・「練習試合」の3択です。「規定未到達者も含む」チェックボックスは初期値オフで、オンにすると規定未到達者も取得・表示します。変更すると選択条件の一覧を取得し、元ページへのリンクにも条件を引き継ぎます。

スマホでも成績画面のタブはmainと同じ共通スタイルの文字サイズ・余白で横並びにし、「成績入力」「成績登録確認」の右に「打席成績一覧」「個人成績」を表示します。収まらない場合はタブ内を横スクロールできます。年・試合属性・対戦チーム・大会名の選択欄は2列に揃えます。取得日時と更新ボタンは専用の枠にまとめ、他画面と同じ青色・角丸・余白を使います。表だけを横スクロールでき、画面全体が横に広がらない構成です。

横スクロール中も背番号・選手名は固定表示します。項目名を押すとブラウザー内で昇順・降順を切り替えます。並べ替えによる追加通信はありません。成績一覧では選択中の年・試合属性で表示されている選手の各項目の最大値を赤色で表示し、同率1位が複数いる場合は全員を赤色にします。0（.000などの率も含む）と欠損値は対象外です。「表示を更新」はキャッシュの範囲で最新の取得結果を確認する操作で、外部サイトの強制再取得ではありません。

## 野手成績・投手成績の切り替え

成績一覧内に、成績入力と同じスタイルの「野手成績」「投手成績」タブを配置します。初期表示は野手成績で、投手成績は初めてタブを押したときに取得します。切り替え時も年（通算を含む）・試合属性・対戦チーム・大会名・規定未到達者の条件を保持し、並べ替えは背番号昇順へ戻します。

投手の取得元は [YGファイヤーズの投手成績](https://teams.one/teams/ygfires/stats/pitchers_table) です。試合数・勝・ホールド・セーブ・敗・勝率・防御率・投球回・投球数・失点・自責点・完投・完封・被安打・被本塁打・奪三振・与四球・与死球・ボーク・暴投の20項目を、元ページの表記のまま表示します。投球回は「157回2/3」「0回0/3」を読み取り、並べ替えでは回＋端数/3で比較します。防御率などの「ー」は欠損値として末尾に並べます。

投手用APIは `/api/teamsone/pitchers`、野手用は従来の `/api/teamsone/batters` です。共通の取得処理で15分キャッシュ・8秒タイムアウト・24時間の前回データ保持を使い、種類と全絞り込み条件ごとにキャッシュ・同時要求・失敗時の再試行を分離します。投手から野手へ素早く切り替えても、遅れて届いた投手データは野手表に表示しません。個人成績でも野手・投手を切り替えられ、表示中の種類のデータを使います。

## 個人成績

個人成績内の「野手成績」「投手成績」で切り替えます。初期表示は野手成績で、投手は初めて開いたときに取得します。種類ごとに表示・並べ替え・取得結果を保持します。非表示になった種類は新しい年別取得を止め、表示中の種類では最大2件ずつ取得します。

ログインしている本人のTeams.one成績を表示します。今年の一覧を正常に取得でき、本人の成績が掲載されていない場合は「今年の成績」カードを非表示にし、種類の切り替えタブと年別・通算表のみ表示します。成績の値が0でも本人の行がある場合はカードを表示します。読込中・取得失敗・同姓同名の照合不可・前回データの場合は、成績なしと判定せず案内を残します。管理者が成績入力用に選んだ選手には連動しません。今年は日本時間の現在年を使い、年が変わると年別一覧にも追加します。

- 今年：打率、HR、打点、盗塁、得点、出塁率、長打率、得点圏打率、OPS、安打、二塁打、三塁打、四球、死球、三振、犠打、犠飛、併殺打、失策、盗塁阻止、試合数の21項目をカード表示します。各項目のチーム内1位・2位・3位には金・銀・銅の王冠と順位を表示します。王冠の対象・順位の比較相手はTeams.oneで今年の規定に到達している選手のみで、三振・併殺打・失策も含め、すべて数値の多い順です。同率は同順位（例：1位・1位・3位）、数値が0（率の.000なども含む）・数値なし・本人を照合できない場合は王冠を付けません。本人の数値は規定未到達でも表示しますが、規定未到達の場合は王冠を付けません。王冠用に今年の規定到達者のみの一覧も取得し、既存の15分キャッシュを共有します。順位用データがないときは全選手の順位に切り替えず、王冠を非表示にします。
- 今年の投手成績：勝ち数・勝率・防御率・ホールド・セーブ・奪三振・投球回・完封・試合数の9項目を、野手と同じカード形式で表示します。王冠は今年の規定到達者の1位のみ（金）で、同率1位にも表示します。防御率は小さい順、その他8項目は多い順です。規定未到達・数値なし・0（防御率0.00や投球回0回0/3を含む）は王冠を付けません。野手の1〜3位の表示は維持します。
- 年別：2022年〜現在年の野手26項目または投手20項目を既存の成績表と同じ横スクロール表で表示し、年度を固定します。項目名の下の▲▼で並び順を示し、列幅を変えずにソートできます。
- 通算：年別一覧の最下行（初期表示では2022年の直下）に、表示中の種類と同じ項目で表示します。並べ替え時も通算行は最下部に固定します。年別成績を足したり率を平均したりせず、Teams.oneの年度指定なしの公開値をそのまま使います。

個人成績は規定未到達選手も含めて取得します（`unreached=true`）。氏名をNFKCで正規化し、半角・全角の空白を除いて照合します。同姓同名の複数候補がいる場合のみ背番号で絞り込み、番号のみ一致する別名の選手や特定できない複数候補は表示しません。過去に背番号が変わっていても、氏名が一意なら照合します。未掲載・照合不可・取得失敗は案内を表示し、数値をゼロと誤認しないよう「—」で表します。

個人成績タブを初めて開いたときに今年の全選手の数値と規定到達者の一覧を先に取得し、残りの年度と通算を最大2件の並列通信で読み込みます。現在は年別5件＋通算1件＋今年の規定到達者1件の7条件で、今後は年度ごとに1条件増えます。各条件の結果と失敗時の再試行は既存APIでキャッシュし、別の利用者でも拠点内で再利用します。ブラウザでも条件ごとに保持し、ポーリングしません。規定未到達者を含む条件と含まない条件のキャッシュは分離します。個人成績は、同じ年で「規定未到達者も含む」をオンにした一覧とキャッシュを共有します。公開チーム一覧からブラウザで本人を抽出するため、このAPIは個人情報を新たに公開するものではなく、元から公開済みの成績を返します。

## 通信と負荷

- 新しいタブを初めて開いたときや選択条件を変更したときに `/api/teamsone/batters?year=2026&gameType=official` のようなAPIを呼びます。入力画面・登録確認画面の表示だけでは外部取得を行いません。
- タブを切り替えても一覧を保持します。15分以内の再表示でAPIを繰り返し呼ばず、自動ポーリングも行いません。
- サーバーは年・試合属性・規定到達条件・対戦チーム・大会名の組み合わせごとに取得・解析した一覧を15分間再利用します。利用されていない条件を先回りして取得しません。Worker内のメモリーに加え、Cloudflare Cache APIで拠点内の複数Worker間でも再利用します。同じWorkerで同時に届いた同一条件のリクエストは1回の取得を共有します。
- Cache APIは拠点ごとのキャッシュです。複数拠点・キャッシュの消失・並行したコールドスタートでは追加取得が発生するため、世界全体で15分に1回という保証ではありません。詳細は [CloudflareのCache API](https://developers.cloudflare.com/workers/runtime-apis/cache/) を参照してください。
- DBの読み書きや新しいDB移行は追加していません。取得・並べ替え・表示によってアプリ内の登録成績やTeams.one側の数値は変更しません。
- 外部取得は8秒でタイムアウトし、HTMLは最大512,000バイトまで読み取ります。広告やスクリプトを実行したり、取得したHTMLを画面に埋め込んだりしません。

初回取得とキャッシュ期限後の再取得はTeams.oneとの通信を待ちます。キャッシュ中の通常表示は保存済みの一覧を返し、外部通信・HTMLの再解析を省きます。

## 取得できない場合

Teams.oneの障害やHTML構造の変更を検出した場合、同一条件で最後に正常取得した成績を最大24時間保持し、取得日時と前回データであることを画面に表示します。正常なキャッシュを空の成績で上書きしません。再試行は60秒間抑え、この状態も拠点内で共有します。

保存済みデータがない場合や24時間を超えた場合は503と案内文を返します。Cache APIが使えない環境ではWorker内のメモリーで再利用します。
