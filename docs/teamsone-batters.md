# Teams.oneの打者成績一覧

成績画面の「成績登録確認」の隣に「打者成績一覧」、その隣に「個人成績」タブを追加しています。

取得元は [YGファイヤーズの打者成績一覧](https://teams.one/teams/ygfires/stats/batters_table) です。選択した年・試合属性の条件で表示された選手・26項目の数値を取得し、打率などの先頭の小数点や桁数もそのまま表示します。その他の絞り込み条件は元ページの既定値を使います。

年は2022年から日本時間の現在年まで選択でき、2027年以降も年が変わると自動的に追加されます（画面の再表示・再読み込み時に反映）。初期値は現在年です。試合属性は「試合属性」（指定なし）・「公式戦」・「練習試合」の3択です。「規定未到達者も含む」チェックボックスは初期値オフで、オンにすると規定未到達者も取得・表示します。変更すると選択条件の一覧を取得し、元ページへのリンクにも条件を引き継ぎます。

スマホでも成績画面のタブはmainと同じ共通スタイルの文字サイズ・余白で横並びにし、「成績入力」「成績登録確認」の右に「打席成績一覧」「個人成績」を表示します。収まらない場合はタブ内を横スクロールできます。年・試合属性の選択欄は2列に揃えます。取得日時と更新ボタンは専用の枠にまとめ、他画面と同じ青色・角丸・余白を使います。表だけを横スクロールでき、画面全体が横に広がらない構成です。

横スクロール中も背番号・選手名は固定表示します。項目名を押すとブラウザー内で昇順・降順を切り替えます。並べ替えによる追加通信はありません。打者成績一覧では選択中の年・試合属性で表示されている選手の各項目の最大値を赤色で表示し、同率1位が複数いる場合は全員を赤色にします。0（.000などの率も含む）と欠損値は対象外です。「表示を更新」はキャッシュの範囲で最新の取得結果を確認する操作で、外部サイトの強制再取得ではありません。

## 個人成績

ログインしている本人のTeams.one成績を表示します。管理者が成績入力用に選んだ選手には連動しません。今年は日本時間の現在年を使い、年が変わると年別一覧にも追加します。

- 今年：打率、HR、打点、盗塁、得点、出塁率、長打率、得点圏打率、OPS、安打、二塁打、三塁打、四球、死球、三振、犠打、犠飛、併殺打、失策、盗塁阻止、試合数の21項目をカード表示します。各項目のチーム内1位・2位・3位には金・銀・銅の王冠と順位を表示します。王冠の対象・順位の比較相手はTeams.oneで今年の規定に到達している選手のみで、三振・併殺打・失策も含め、すべて数値の多い順です。同率は同順位（例：1位・1位・3位）、数値が0（率の.000なども含む）・数値なし・本人を照合できない場合は王冠を付けません。本人の数値は規定未到達でも表示しますが、規定未到達の場合は王冠を付けません。王冠用に今年の規定到達者のみの一覧も取得し、既存の15分キャッシュを共有します。順位用データがないときは全選手の順位に切り替えず、王冠を非表示にします。
- 年別：2022年〜現在年の26項目を既存の成績表と同じ横スクロール表で表示し、年度を固定します。項目名の下の▲▼で並び順を示し、列幅を変えずにソートできます。
- 通算：年別一覧の最下行（初期表示では2022年の直下）に、同じ26項目で表示します。並べ替え時も通算行は最下部に固定します。年別成績を足したり率を平均したりせず、Teams.oneの年度指定なしの公開値をそのまま使います。

個人成績は規定未到達選手も含めて取得します（`unreached=true`）。氏名をNFKCで正規化し、半角・全角の空白を除いて照合します。同姓同名の複数候補がいる場合のみ背番号で絞り込み、番号のみ一致する別名の選手や特定できない複数候補は表示しません。過去に背番号が変わっていても、氏名が一意なら照合します。未掲載・照合不可・取得失敗は案内を表示し、数値をゼロと誤認しないよう「—」で表します。

個人成績タブを初めて開いたときに今年の全選手の数値と規定到達者の一覧を先に取得し、残りの年度と通算を最大2件の並列通信で読み込みます。現在は年別5件＋通算1件＋今年の規定到達者1件の7条件で、今後は年度ごとに1条件増えます。各条件の結果と失敗時の再試行は既存APIでキャッシュし、別の利用者でも拠点内で再利用します。ブラウザでも条件ごとに保持し、ポーリングしません。規定未到達者を含む条件と含まない条件のキャッシュは分離します。個人成績は、同じ年で「規定未到達者も含む」をオンにした一覧とキャッシュを共有します。公開チーム一覧からブラウザで本人を抽出するため、このAPIは個人情報を新たに公開するものではなく、元から公開済みの成績を返します。

## 通信と負荷

- 新しいタブを初めて開いたときや選択条件を変更したときに `/api/teamsone/batters?year=2026&gameType=official` のようなAPIを呼びます。入力画面・登録確認画面の表示だけでは外部取得を行いません。
- タブを切り替えても一覧を保持します。15分以内の再表示でAPIを繰り返し呼ばず、自動ポーリングも行いません。
- サーバーは年・試合属性の組み合わせごとに取得・解析した一覧を15分間再利用します。利用されていない条件を先回りして取得しません。Worker内のメモリーに加え、Cloudflare Cache APIで拠点内の複数Worker間でも再利用します。同じWorkerで同時に届いた同一条件のリクエストは1回の取得を共有します。
- Cache APIは拠点ごとのキャッシュです。複数拠点・キャッシュの消失・並行したコールドスタートでは追加取得が発生するため、世界全体で15分に1回という保証ではありません。詳細は [CloudflareのCache API](https://developers.cloudflare.com/workers/runtime-apis/cache/) を参照してください。
- DBの読み書きや新しいDB移行は追加していません。取得・並べ替え・表示によってアプリ内の登録成績やTeams.one側の数値は変更しません。
- 外部取得は8秒でタイムアウトし、HTMLは最大512,000バイトまで読み取ります。広告やスクリプトを実行したり、取得したHTMLを画面に埋め込んだりしません。

初回取得とキャッシュ期限後の再取得はTeams.oneとの通信を待ちます。キャッシュ中の通常表示は保存済みの一覧を返し、外部通信・HTMLの再解析を省きます。

## 取得できない場合

Teams.oneの障害やHTML構造の変更を検出した場合、同一条件で最後に正常取得した成績を最大24時間保持し、取得日時と前回データであることを画面に表示します。正常なキャッシュを空の成績で上書きしません。再試行は60秒間抑え、この状態も拠点内で共有します。

保存済みデータがない場合や24時間を超えた場合は503と案内文を返します。Cache APIが使えない環境ではWorker内のメモリーで再利用します。
