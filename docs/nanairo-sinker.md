# 後藤の投げろ！七色のシンカー！

ゲームIDは `goto-nanairo`、画面は `/game/goto-nanairo`。YGミニゲーム一覧から開きます。投手は後藤。YGの打者5人と、全員フルカウント（3ボール・2ストライク）開始・ファウルなしで1球ずつ勝負します。全5球の合計ポイントを競います。2人目以降の打者名は打席が始まるまで伏せ、開始時に名前を表示します。阿部・石畑の名前やレア表示も、その打席が始まるまで隠します。

## 操作と判定

1. サーバーが球種、変化の左右、リリース目標時刻（1,500～2,300ms）を抽選し、画面で球種を表示します。
2. ストライクゾーンを3×3に分けた9マスからコースを選択します。選んだマスの中心（各軸16.67・50・83.33）を狙います。キーボードでは選択中のマスにフォーカスし、矢印キーで上下左右のマスへ移動できます。端でそれ以上移動しません。
3. 「投球モーション開始」でゲージが動きます。金の線に重なった瞬間に「今だ、投げろ！」を押します。Space / Enterでも操作できます。
4. `performance.now()` の経過時間を送信し、サーバーが保存済みの目標時刻からズレ、失投、打者のスイング、空振り・インプレー、得点を判定します。

| 判定 | ズレの絶対値 | 失投率 |
| --- | --- | --- |
| PERFECT | 10ms以内 | 基本失投率 |
| GOOD | 10ms超～40ms以内 | 基本＋5ポイント |
| MISS | 40ms超 | 基本＋35ポイント |

リリースの許容幅はPERFECT ±10ms、GOOD ±40msです。ゲージの判定ゾーンと画面の説明も同じ基準を使用します。

4秒間リリースしない、またはモーション中に別のタブ・アプリへ移ると4,000msで投球し、MISSになります。描画フレーム数で精度を判定しません。

成功した投球は選んだマスの中心に届きます。失投すると35～130の距離（ゾーンの幅を100とする座標）でランダムな方向にズレます。失投した球がストライクになることも、ボール球を打者が振ることもあります。大きく外れた暴投では後藤の「あ！ごめ～ん！」を表示します。

見送りはゾーン内なら見逃し三振、外なら四球。スイングは空振りなら三振、接触なら凡打・単打・二塁打・三塁打・本塁打です。ファウルと3球三振ボーナスはありません。PERFECTでも三振確定ではありません。PERFECT時は通常、空振り率＋3ポイント・安打率−3ポイントで少し抑えやすくします。北澤・千明・池原・レア打者の追加効果は打者欄を参照してください。

ストライクゾーンは赤が打者の得意コース、青が苦手コース、色なしが通常コースです。番号は上段が左から1・2・3、中段が4・5・6、下段が7・8・9です。指定のないマスは通常コースです。右打者として画面左列をインコース、右列をアウトコースと扱います。「真ん中」は中央の1マス、高めは上段、低めは下段です。各マスの色とサーバー判定は同じコース定義を使用します。画面の打者説明文は維持します。

得意コースは空振り率−16ポイント・安打率＋20ポイント、苦手コースは空振り率＋16ポイント・安打率−12ポイント。三澤の得意コースはさらに空振り率−5ポイント・安打率＋5ポイントです。通常コースには相性の補正を付けません。ゾーン外はコースボーナスの対象外です。

実際に届いた位置がゾーン内の得意コースで三振を取ると追加＋400点。失投で苦手コースやゾーン外へ外れた場合は加算しません。選択中のマスは金色の枠で強調します。球種との相性・リリース精度・限界突破も別に反映します。

## 球種

球種はシンカー7種類のみ。ストレート・スライダー・カーブの20%を通常・高速・急降下・横滑り・ジグザグに振り分けています。以前の対戦履歴の球種名は維持し、途中再開時の未投球の旧球種は通常シンカーに置き換えます。

空振り率は「打者がスイングした場合」の基準値です。ミート3、低め・端・中央の補正がないコースでの値を記載しています。

| 球種 | 倍率 | 出現率 | 軌道 | 基本失投率 | 基準空振り率 |
| --- | --- | --- | --- | --- | --- |
| 通常シンカー | 1.0 | 40% | 斜め下に沈む | 14% | 45% |
| 高速シンカー | 1.0 | 20% | 高速で鋭く落ちる | 18% | 55% |
| 急降下シンカー | 1.0 | 12% | 打者の手前で垂直落下 | 22% | 60% |
| 横滑りシンカー | 1.0 | 12% | 横に大きく曲がって沈む | 20% | 55% |
| ジグザグシンカー | 1.2 | 8% | 左右に何度も変化 | 27% | 68% |
| 消えるシンカー | 1.2 | 5% | 一瞬消えて再出現 | 32% | 75% |
| 七色の究極シンカー | 1.5 | 3% | 虹色に光り、異常な軌道で変化 | 38% | 85% |

難易度調整で、全球種の基本失投率を従来から10ポイント引き上げています。究極シンカーの失投率はPERFECT 38%、GOOD 43%、MISS 73%。登場時に「だから俺はシンカーを七種類にした。」を表示します。投球アニメーションは全7種類で異なり、消える球は途中で非表示、究極は虹色の軌道です。アニメーションの終点はサーバーの判定に使った到達位置と一致します。OSの動きを減らす設定では投球アニメーションを短縮します。

通常8人から、重複なしで5人を重み付き抽選します。北澤の重みは0.8、他は1なので、北澤の出現は少し低くなります。抽選後、石畑を4人目、阿部を5人目にそれぞれ独立して2%で置き換えます。同時に登場する場合もあります。後藤は投手専用。途中の旧プレイの対戦履歴は維持します。

ミートは空振り・安打率、パワーは当てた後の長打・本塁打率に影響します。菅・小林の限界突破は勝負時に15%で抽選し、その打席だけミート・パワーが同時に10になります。

八巻・川鍋は究極シンカーにめっぽう強く、究極シンカーに対してのみ振ったときの空振り率−40ポイント・当てたあとの安打率＋20ポイントを付けます。PERFECT・GOOD・MISSのすべてで適用し、コース相性・失投・PERFECT時の通常補正と合算します。確率の上限・下限も維持します。

PERFECT時の通常優遇は空振り率＋3ポイント・安打率−3ポイント。北澤・千明にはさらに空振り率＋40ポイント・安打率−20ポイント、池原にはさらに空振り率＋20ポイント・安打率−10ポイントを付けます。八巻の旧シンカー耐性・池原の旧究極シンカー弱点は廃止します。リリース精度による失投率の差は全打者共通です。

阿部・石畑はPERFECTまたはGOODで失投しなかった場合、通常のスイング・安打抽選より優先して99%で抑え、1%で場外ホームランになります。三振・凡退で抑えると石畑は追加＋1,000点、阿部は追加＋1,500点です。ボーナスにもその打席の球種倍率が掛かります。場外ホームランは通常の本塁打と同じ基本−2,000点で、ボーナスはありません。MISSまたは失投の場合は通常の判定に戻り、四球や被安打も発生します。

レア打者の打席開始時は金色の枠・きらめく星・本人の写真を使った「超レア！○○、参上！」を表示します。「ラッキー打者と勝負！」またはEscで閉じて投球します。阿部・石畑が連続登場する場合は、それぞれの打席で演出します。OSの動きを減らす設定では登場アニメーションを停止します。

写真は `public/nanairo/goto.jpeg`、打者は `public/nanairo/{yamaki,kan,kawanabe,ikehara,misawa,kobayashi,ishihata,chiaki,abe,kitazawa}.png`。ゲーム内のキャラクター定義を使い、実際の選手登録や打撃成績を変更しません。

## 得点

| 結果・条件 | ポイント |
| --- | --- |
| 空振り三振 | ＋1,000 |
| 見逃し三振 | ＋800 |
| PERFECTで空振り三振・見逃し三振 | 追加＋500 |
| 2人連続三振の2人目 | 追加＋500 |
| 3人以上連続三振 | 3人目以降毎回追加＋1,000 |
| 石畑を三振・凡退で抑える | 追加＋1,000 |
| 阿部を三振・凡退で抑える | 追加＋1,500 |
| 北澤から空振り三振・見逃し三振を取る | 追加＋400 |
| 打者の得意コースで三振 | 追加＋400 |
| ヒット（単打） | −500 |
| 二塁打 | −1,000 |
| 三塁打 | −1,500 |
| 四球 | −500 |
| 本塁打 | −2,000 |
| 凡打 | ＋500 |

三振以外で連続記録をリセット。その打席の基本点にPERFECT三振・連続三振・打者別（石畑・阿部・北澤）・得意コースのボーナスを加算してから、球種の倍率を一度だけ掛けます。PERFECT三振の＋500点は空振り三振・見逃し三振の両方が対象で、GOOD・MISSや凡打・被安打・四球には加算しません。北澤の＋400点は空振り三振・見逃し三振のみで、凡打・被安打・四球では加算しません。PERFECT三振と北澤ボーナスは合算でき、両方に球種倍率を適用します。倍率は減点にも適用し、過去の打席や累計ポイントには掛けません。例：ほかのボーナスがない場合、究極シンカーでPERFECTの空振り三振は（1,000＋500）×1.5＝＋2,250点、さらに得意コースなら（1,000＋500＋400）×1.5＝＋2,850点、本塁打は−3,000点、四球は−750点です。

究極シンカーの三振ボーナス＋3,000点は廃止しました。途中の負の合計は保持し、5人終了時の合計が負なら最終記録は0点です。以前の連続倍率、3者連続一律＋1,500、3球三振ボーナスは使用しません。保存済みの旧結果の得点は維持し、新しく投げる打席から球種倍率を適用します。

## 保存と確認

既存の `mini_game_runs` / `mini_game_scores` を使い、`0010_mini_games.sql` 適用済みならDB移行は不要。球種・打者抽選、失投、打席結果、得点はすべてサーバーで決めます。クライアントの申告スコアや球種を採用しません。

開始時に5人の打者と1球目の準備状態を保存します。`nanairo-pitch` はコース `target: { x, y }`（各0～100）と `elapsedMs`（0～4,000）を受け取り、1球分を確定して次の球を準備します。同じリクエストIDで再送しても二重加算しません。別タブの古いプレイID・ターン番号では更新を拒否します。

1プレイの結果は最大5球だけ保存し、新しいプレイで置き換えます。5人終了時だけ自己ベストを更新し、既存のゲームとは別のランキングで比較します。

自動確認：

```sh
node --test tests/nanairo.test.mjs tests/nanairo-store.test.mjs
npx tsc --noEmit --incremental false
npm run build
```

テストは球種の分布、失投補正の境界、打者の相性、限界突破、ボーナス・減点、5球終了、軌道の終点、不正入力、実際の保存SQLによる再開・再送・ランキングを確認します。保存テストには隔離したインメモリSQLiteを使い、ローカル・本番D1には書き込みません。

手動確認は、ログイン→ゲーム一覧→コース指定→リリース→5人終了→ランキング→再挑戦の順で行ってください。スマホのタップとPCの矢印・Space / Enter、通信失敗後の再送、途中再読み込み、魔球・暴投の演出も確認します。
